# Security

The editor runs locally in the browser. Projects and generated videos are not uploaded by the application. Browser storage is specific to the current origin; download a JSON project to keep a portable copy.

For a security issue, use GitHub's private vulnerability reporting on this repository when available. If it is unavailable, open an issue asking for a private reporting channel without including an exploit, credentials, or private project data. Do not post secrets in public issues.

A missing required numeral asset blocks rendering and export until it can be loaded. Invalid saved projects are retained for recovery instead of being overwritten on startup.
